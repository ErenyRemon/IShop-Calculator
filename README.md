# IShop-Calculator
IShop Calculator
✨ My programming journey is growing—one line of code at a time!
Today, I built a simple yet interactive Python 🐍 project: a shopping basket calculator.
The program allows users to enter the names and prices of the items in their basket and then calculates the total cost. It even gives the option to review all items before showing the total.

📌 What I used:

Lists to store item names and prices

Loops to gather input

Conditionals to add interaction with the user

It's a small project, but it's a big step in my learning journey. Every small project adds up to something greater! 💻
